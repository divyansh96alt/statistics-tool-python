# Python Statistics Tool

A beginner-friendly Python program that calculates basic statistics from a list of numbers.

## Features

* Count
* Mean
* Median
* Mode
* Minimum
* Maximum
* Range
* Sample variance
* Sample standard deviation

## How to use

Make sure Python is installed on your computer.

Run the program:

```bash
python statistics_tool.py
```

Then enter numbers separated by spaces.

Example:

```text
10 20 20 30 40
```

## Example output

```text
Count: 5
Mean: 24.00
Median: 20.00
Minimum: 10.00
Maximum: 40.00
Range: 30.00
Mode: 20.00
```
